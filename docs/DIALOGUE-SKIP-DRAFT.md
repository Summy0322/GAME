# 跳過對話試玩草稿

本分支接續聲音設定，單獨提供選用的對話跳過功能。

## 操作

1. 主畫面左下角齒輪 →「跳過對話」→「密碼解鎖」。
2. 輸入 `skip_dial`，按「解鎖並開啟」。僅目前這次開啟網站有效，重新整理後預設關閉。
3. 劇情右上角出現 `>>`。按下後選「稍後」留在目前對話，或「直接遊玩」進入下一個小遊戲。
4. 沒有下一個遊戲的章末，改為確認「完成本章」。
5. 回到主畫面設定可關閉功能。

## 流程

- 第一章仍需依序進入三個小關卡。結果後可再跳過劇情，失敗後的跳過沿「繼續故事」前往下一關，原本「再挑戰一次」選項保留。
- 第二章保留問答遊戲，再進入記憶配對。問答獲得的懲罰減免依實際答題分數保留，不自動作答或給獎勵。
- 第三章保留命名、地圖選店、拖曳操作與付款／蒐集流程。店家介紹可跳到實際遊戲，成功後的對話可跳到原本的物品蒐集流程。沒有自動蒐集或支付。
- 遊戲、問答作答、地圖與命名畫面不顯示跳過按鈕；一般對話與旁白可顯示。
- 不自動授予遊戲成功，仍使用原有結算及章節完成邏輯。原本可在失敗後繼續故事的規則保持一致。

## 驗證

新增測試涵蓋密碼、預設關閉、取消與重複確認、六份章節資料的路線、第一章三關與失敗分支、第二章實際獎勵、第三章店家前後對話、停止後舊回呼失效。

需實機確認：手機橫向的設定視窗完整顯示、右上角按鈕位置、三章連續試玩與第三章購物流程。前端密碼用於避免誤開，不作為帳號或資料的安全驗證。
