# 跳過對話試玩草稿

本分支接續聲音設定，單獨提供選用的對話跳過功能。

## 操作

1. 主畫面左下角齒輪 →「跳過對話」→「密碼解鎖」。
2. 輸入 `skip_dial`，按「解鎖並開啟」。僅目前這次開啟網站有效，重新整理後預設關閉。
3. 劇情右上角出現 `>>`。按下後選「稍後」留在目前對話，或「直接遊玩」進入下一個小遊戲。
4. 沒有下一個遊戲的章末，改為確認「完成本章」。
5. 回到主畫面設定可關閉功能。

## 流程

- 第一章仍需依序進入三個小關卡。結果後可再跳過劇情，失敗後的跳過沿「繼續故事」前往下一關，原本「再挑戰一次」選項保留。
- 第二章保留問答遊戲，再進入記憶配對。問答獲得的懲罰減免依實際答題分數保留，不自動作答或給獎勵。
- 第三章開場按跳過，直接進中藥行；命名畫面也可跳過，使用現有名稱或預設「小旅人」。成功後按跳過，完成既有扣款／物品紀錄，略過個別蒐集動畫，接著進刀行、雜貨店。最後一次跳過略過總蒐集動畫及章末文字，完成本章。
- 第三章中途從地圖使用跳過，依中藥行、刀行、雜貨店順序找未完成店家，不重複扣款或遊玩已完成項目。關閉遊戲回地圖不會記為成功或完成物品。沒有按跳過則保留自由逛店與動畫。
- 遊戲與問答作答期間不顯示跳過按鈕；第三章地圖可用來前往下一間未完成店家。
- 不自動授予遊戲成功，仍使用原有結算及章節完成邏輯。原本可在失敗後繼續故事的規則保持一致。

## 驗證

「重設章節進度」同時清除兩模式的遊戲進度、問答獎勵、第三章店家／物品、名字與錢袋（恢復20枚），取消舊載入工作；聲音設定與當次跳過解鎖不受影響。

第三章拖曳遊戲的操作物件、放置區及店家背景為必要圖片：載入成功才進場；失敗或逾時顯示「重新載入／返回地圖」，不在缺少操作圖片時開始。音樂仍按需串流，慢網路可能延後播放，且仍受手機的音訊啟動限制。

測試涵蓋密碼、預設關閉、取消與重複確認、六份章節資料路線、第一章三關與失敗分支、第二章實際獎勵、第三章兩模式完整三店串接及逐次扣款（20→15→10→6）、略過動畫、地圖接續與停止後舊回呼失效。

需實機確認：手機橫向的設定視窗完整顯示、右上角按鈕位置、三章連續試玩與第三章購物流程。前端密碼用於避免誤開，不作為帳號或資料的安全驗證。
