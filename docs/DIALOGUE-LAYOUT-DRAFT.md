# 對話比例草稿

本次僅調整對話呈現；16:9 舞台、劇情台詞、逐字速度與小遊戲邏輯維持原設定。

- 閱讀區寬 88%，底部留 1%；依角色分配高度：阿斗仔 30%、中藥行／刀行 26%、媽媽／雜貨店及其他素材 24%。保留已確認的角色尺寸與貼底站位，降低對話框上緣以露出臉部。
- 恢復原本對話框 15px 圓角、姓名牌 25px 圓角；姓名牌跨在對話框上緣（一半在外、一半在內），上內距依姓名牌半高加閱讀留白計算，避免遮住第一行文字。
- 桌機舞台 1280×720：一般字級從 20px 上限改為 25.2px，小朋友版 27.36px；桌機行距分別 1.65、1.8；舞台高 430px 以下收為 1.5，減少閱讀區壓力。
- 手機橫向保留字級下限 16／17px；仍使用原本注音字型，不以縮字硬塞長台詞。
- 角色容器貼齊舞台底端（bottom: 0），高 80%；圖片維持比例、以底部對齊，保留稍大的角色呈現，避免看起來懸浮在背景上。
- 名牌、邊框、閱讀內距與選項色彩一起調整；名稱原有左／中／右設定也有對應樣式。
- 問答維持兩欄兩列，按鈕至少 44px 高；選項區上移，避開加高的對話框。

覆寫集中在 css/dialogue-layout.css，由 index.html 載入。草稿不合適時可單獨撤回。
service worker 快取升為 game-v21，包含新樣式。

## 比較方式

在專案資料夾執行 `node tests/serve-layout.cjs`，開啟：

http://127.0.0.1:4173/GAME/tests/dialogue-comparison.html

可比較原版／草稿、一般／長台詞、四選項、兩種模式及五個角色，提供桌機、手機橫向、平板尺寸。
這個測試頁依賴本機測試伺服器的場景注入，不能直接以 GitHub Pages 或一般 Live Server 的比較頁取代。

## 已驗證與限制

- 原有 56 項自動測試通過。
- Chrome 檢查 1280×720、844×390、640×360、1024×768，雙模式及安全區：8 組配置各掃描全部 8 題（64 次），四選項無捲軸、按鈕文字不截斷、題目不溢出、選項不重疊對話框。
- 檢查頁：/GAME/tests/dialogue-layout-check.html。
- 已視覺檢查阿斗仔、媽媽的桌機畫面及小朋友版手機長台詞／問答。
- 較長台詞在小螢幕、注音模式下仍可能需要捲動，保留完整內容；本草稿未加入自動分頁。
- 角色素材的透明留白與畫風仍沿用原檔，沒有修改圖片；其餘角色與實際手機觸控體感需試玩比較。

本次追加：以素材中下巴的位置目視設定閱讀區高度，不是自動臉部辨識。Chrome 桌機媽媽下巴估計位置至對話框上緣約 16px；已比較阿斗仔及媽媽。新角色或不同裁切圖片仍需個別檢查。

第二章三個一般選項改成上排兩個、下排一個寬按鈕，移除該組容器高度限制與捲軸，保留選項順序／功能與暖杏金配色。比較頁新增三選項場景；版面掃描加入第二章雙模式實際三選項資料。
