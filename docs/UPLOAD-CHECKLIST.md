# 2026-11-02 收尾與上傳說明

本次收尾補上 Service Worker 安裝失敗保護：任一預存程式檔下載失敗時，新版安裝會失敗，既有可用版本繼續保留。快取版本為 `game-v68`。這項保護不代表可以省略上傳檔案，也不會讓首次造訪的玩家自動取得舊版。

## 上傳

1. 以本資料夾 `GAME` 為準，保留 `index.html`、`style.css`、`css/`、`js/`、`assets/`、`sw.js`、`manifest.json` 的相對位置。不要混用旁邊的 `music-upload-staging` 舊副本。
2. 將內容放在網站的 `/GAME/` 路徑；目前 Service Worker 與 PWA 設定使用此路徑。
3. 儘量同一批發布完整檔案。若必須分批傳送，先上傳資源與程式，最後上傳 `index.html` 和 `sw.js`。
4. 更新後關閉所有既有遊戲分頁再重新開啟，讓等待中的新版 Service Worker 接手；進行中的遊戲請先結束。
