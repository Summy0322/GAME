# 無限防守：後期交錯波

交錯防守已併入無限模式，不再提供獨立入口、三段短局或獨立紀錄。它是後期的節奏變化，而非另一套玩法。

- 第 65 波首次出現，此後每十波一次（75、85、95…）。避開 AOE 的整十波及順序題。
- 第一次使用兩個普通目標；之後交替普通／重擊的出場先後，方向隨機旋轉。同時最多兩個威脅。
- 每個普通目標有獨立期限，倒計條使用共同比例，較短的條代表較急迫。可連續滑動，不鎖定操作順序。
- 重擊沿用五格點燃與格擋，交錯波保留至少成人 220ms／兒童 260ms 的點燃間隔；兒童版的普通目標與飛行時間另有餘裕。
- 命中沿用普通／重擊分數。同波漏接最多扣一命、一次失誤與一次逾時分數；仍可接住另一個目標。
- 全部目標完成或逾時後接回下一波。沿用無限模式 HUD、暫停、結算與分數／波次最佳紀錄。舊原型紀錄保留在儲存區但不混入無限紀錄。

驗證包含指定波次、兩種年齡、連滑、最後一刻命中、提前開盾、暫停、過期手勢、重複回呼、同波雙漏接與最後一命結束。可玩性仍以後續試玩回饋調整。
