# 連續防守：守住街口（第一版原型）

入口：夜間目錄 → 防守挑戰卡片右上「連續玩法」。此入口與故事、限時、無限、練習分開，不更換既有出題。

三段手工編排的短局，共十八個威脅，初始三條命。普通目標與重擊會交錯出現，同時最多兩組；同方向在舊命中特效結束前不安排新目標。小朋友版整體節奏放慢 30%。不使用遮擋、不添加新手勢。

- 普通目標往該方向滑動即可發射。每個目標有獨立時限，時間條使用統一刻度：同樣長度代表相同剩餘時間，避免後出現的快速目標因「滿條」被誤認為較不緊急。剩餘不足約 650ms 時變為暖色，小朋友版同比放慢。
- 重擊沿用正式關卡五格逐一點燃與護盾素材，一般版每格 400ms、小朋友版 520ms；全亮後有 650／845ms 的格擋窗口。護盾持續 500ms，太早開盾會先消失，恢復期間仍可滑動處理其他方向的普通目標。
- 正確輸入立即停止該目標的逾時判定，命中動畫不占作答時限，可連續接另一個方向。每個漏接只扣一次生命，不取消其他已接受的命中；生命歸零才停止後續威脅並結算。
- 空方向可發射，不額外扣命；從舊目標或尚未出現目標時開始的手勢，不會套到後來新出現的目標。
- 每段結束保留命中回饋與短暫喘息，再進下一段。完成三段或生命歸零結算，顯示接住數、剩餘生命與漏接類型。普通目標 +50、重擊 +100、漏接 -25，最低零分；全接住為 1150 分。

所有生成、時限、護盾邏輯及飛行使用同一遊戲時鐘。暫停會同時凍結；退出、換場或重開後，舊回呼不能扣命或跳結算。紀錄使用 `rush:defense:<年齡>`，不混入原限時或無限分數。

驗證包含兩種年齡的最大同屏數、同方向間距、最後一毫秒、連滑與亂序命中、早開盾、暫停、過期手勢、一次扣命及生命歸零取消後續生成。瀏覽器實際滑動完成兩種年齡的十八個威脅，並驗證暫停、勝利與逾時失敗。

本版的試玩問題：交錯出題是否比逐波等待更流暢、是否真的會讀取各方向優先度，以及是否只是增加忙碌感。若只感覺更忙，先調整三段編排與空檔，不增加同屏數或速度。
