# 各關介面統一與配對效能

## 排列紀錄

未在目前專案說明中找到製作者明確要求改成 2×6 的紀錄。現有自動排列在橫向舞台上，12 張優先為 3 行、每行 4 張，10 張固定為 2 行、每行 5 張。本次保留排列、卡片數與難度；原本的 `rows`／`cols` 明確設定亦保留。

## 視覺與空間

- 各遊戲採細框、削角、輕陰影與數字資訊層級；故事保留暖色，挑戰保留霧藍／靛藍。
- 限時防守也使用精簡雙角標。配對挑戰資訊移入面板上方的資訊區，先保留資訊空間再計算卡片尺寸。
- 拖曳提示移入下方訊息列；取消浮在接收區上方的提示。三間店家、知識卡、問答與結算按鈕使用共用樣式。
- 付款面板改以 1000px 設計稿寬度搭配現有舞台縮放，避免百分比寬度與縮放重複套用；禁止 flex 再縮窄面板，操作區與按鈕完整包在外框內。小字不再隨面板被重複縮小。

共用樣式位於 `css/game-ui.css`，已加入入口與 Service Worker 快取，版本 `game-v75`。

後續配色修正：故事防守的資訊框、提示、暫停與故事結算按鈕採木棕／米金，覆寫均排除挑戰場景。第三章收集欄及每格去背素材保持透明，不加底色、外框或陰影。已以瀏覽器比對主要挑戰介面的背景、文字、邊框及尺寸，確認與修正前一致。

## 翻牌改善

- 挑戰資訊建立一次，更新時保留愛心及各欄節點；只更改變動數字，避免每 100ms 重建內容。
- 配對統計改用不依賴版面讀取的 `textContent`，相同數值不重複寫入。
- 移除配對主面板與資訊列的兩層背景模糊；翻牌採 300ms transform 動畫、預備合成層與背面隱藏，減少動態偏好下近乎即時切換。
- 卡面圖片採非同步解碼；配對成功／失敗的判定、分數與原本觀察時間保留。

這些是程式端優化，未量測製作者原電腦的幀率，不能由隱藏瀏覽器結果直接推論每台裝置的流暢度。
