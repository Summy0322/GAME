# 故事第一章防守教學

三個小關在同一瀏覽器、同一年齡模式第一次進入時，先開啟可操作的短教學：

- 第 1 小關：跟著手指往右滑動一次，再練習遇到石頭停手避開。停手 2.2 秒完成避石頭示範，誤滑可重試。
- 第 2 小關：示範五格以每格 400ms 逐一亮起，全亮後往目標方向滑動格擋。教學不設失敗倒數，會等待玩家操作；太早滑動只提醒重試。
- 第 3 小關：用一根手指繞角色畫圈，順、逆時針均可；教學達到約 280 度後完成。正式旋轉防守同步支援單指畫圈，原本雙指旋轉仍保留。

教學使用暖棕半透明提示與米白文字，SVG 手指和箭頭示範，不增加圖片素材。減少動態效果設定下停用手指循環動畫。示範時隱藏原關卡物件與資訊，避免同時出現兩個角色；暫停按鈕仍可使用。

教學不建立攻擊、不計分、不扣命。完成後按「開始遊戲」才啟動原本波次；右下角一直有「跳過教學」。完成或跳過會記住該小關與年齡模式；封鎖 localStorage 時仍可正常遊玩，只是不記住。中途離開未完成的教學不會標為已完成。

故事防守暫停選單提供「重開並看教學」，可從頭重看該小關並重新開始遊戲。挑戰、無限模式與 Console 順序測試皆不顯示教學或重看入口。

教學計時沿用遊戲時鐘，隨暫停、隱藏分頁與橫豎屏暫停保留進度。重開、換場景和退出會清除事件、畫面及待執行回呼，不會讓舊教學啟動新關卡。
