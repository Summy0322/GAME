# 遊玩容錯與重玩草稿

本批先實作優先推薦的三項，供試玩；不自動合併主程式。

1. 小朋友配對取消連錯額外扣次數，正常配對仍依規則消耗一次。小朋友原本只顯示紅燈的設定改為不顯示紅燈。答題減免改為保護一般配錯：答對兩題可免扣兩次失誤，額度用完後照常消耗機會。青年版連錯懲罰保留。
2. 觸控／觸控筆拖放有 12～24 個螢幕像素的額外接收範圍，依目前縮放計算。先尊重原框內位置；框外則選最近區域，等距不猜測。高亮與放開共用判定，不放寬答案的正誤規則。滑鼠維持精確命中。
3. 防禦與配對失敗畫面提供「再試一次／回到故事」，按鈕同排、空間不足可換排。重玩經由 GameEngine 重新開始相同小遊戲，沿用關卡、模式、卡片數與答題減免配置，清理舊遊戲、音樂、計時器與事件。舊結算事件不得操作新遊戲。第三章拖曳目前沒有獨立失敗結算，未另加重玩按鈕。

一併修正：配對最後一次機會若配成最後一組，正常判成功；若仍未配完其他組，動畫後判失敗。

建議試玩：
- 小朋友版第二章連錯三次，不應額外少一次；先答對題目時，前幾次配錯會出現獎勵保護。
- 手機第三章拖近放置框，預覽高亮應與放開判定一致；兩框正中間不自動選答案，錯分類也不會被當成正確。
- 第一、二章失敗後直接重玩，確認沒有重播劇情、重複回傳或舊音樂殘留。
- 青年版第二章連錯懲罰維持原規則。

驗證：新增六項程式測試涵蓋上述規則與過期重玩事件；連同既有回歸測試共 73 項。手機按鈕排列與手感尚需實機試玩（本機瀏覽器操作目前停用）。
