# 遊玩流程與提示草稿

尚未合併主程式。以本文件描述的最終方案為準。

## 兩章重玩流程

成功或失敗結算都只保留原本橘色「繼續」。失敗後由阿斗仔對話提供橘色「再挑戰一次／繼續故事」，移除上一版的結算雙按鈕及 GameEngine.onRetry。

第一章直接重玩當前小關；第二章直接重新配對，不再繞回介紹／問答選單。第二章重玩使用上一局 MemoryGameV2.penaltyRedemption 的完整額度（不是剩餘額度），新局重設使用次數。這也避免跳過問答的新局，重玩時誤取更早一輪的答題分數。繼續故事維持原本下一關或結局目的地。

## 小朋友配對

恢復紅燈與連錯三次的額外懲罰；答題減免只抵銷這次額外懲罰，不抵銷普通配對成本。原本先扣數字再只顯示減免動畫的問題也已修正，減免時不實際額外扣次／扣秒。

小朋友親手翻過、尚未配對、目前背面朝上的相同兩張牌才可提示。未曾翻開的牌不揭露。每次配對成功重新計時，六秒後檢查，一次只標示一組卡背，三次柔和反白共約 2.1 秒；不自動翻牌、不扣機會。第一次出現時灰條顯示「這兩張你看過囉，試著找找看！」。正在選牌、配對動畫、記憶階段或分頁隱藏時略過；結算、退出與重玩會清理提示計時器及反白。減少動態效果設定下改成短暫靜態標示。

保留上一版最後一次機會可成功配完最後一組的修正。

## 拖曳

保留觸控／觸控筆 12～24 CSS px 的接收容錯，高亮與放開共用判定，等距不猜答案；滑鼠不放寬。正誤規則不變。

## 驗證

75 項程式測試，涵蓋雙模式紅燈／答題抵銷、最後一次配對、已看過卡片提示、提示暫停與退出、兩章選項及上一局減免、觸控接收範圍及既有回歸案例。手機實際排版、兩章節奏與反白視覺仍待試玩；目前本機瀏覽器操作停用，未宣稱已完成手機視覺驗證。
