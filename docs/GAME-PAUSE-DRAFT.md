# 三章暫停草稿（不合併、不發布）

## 操作與行為

- 防禦、記憶配對、問答與第三章拖曳遊戲顯示「Ⅱ」。一般劇情、地圖及結算不顯示。
- 手動按暫停，或切換分頁／App、畫面轉直向時，凍結目前遊戲。
- 返回畫面保持暫停。第一章、第二章及問答按繼續後倒數3秒；第三章按繼續直接恢復。
- 暫停畫面完全遮住卡片，不延長觀察記憶牌的時間。暫停期間不接受背景遊戲操作，Skip也隱藏。
- 返回章節選擇會清理目前遊戲，不算通關、不額外扣款或取得物品。

## 三章處理

1. 防禦遊戲的等待、波次、技能、投射物、旋轉、閃光與動畫全部使用該場遊戲的虛擬時鐘。暫停時保存剩餘時間，恢復不補跑背景工作；動畫時間戳也排除暫停時長。
2. 配對遊戲的記牌、倒數、翻牌、已看過配對提示由同一場遊戲時鐘管理。問答打字與選項在暫停時停止前進。
3. 拖曳時暫停會呼叫原本的取消拖曳程序，還原拖曳前位置，保留已配對物品。延遲回饋與CSS動畫一併凍結。店家知識卡等掛在舞台外的附屬節點在暫停時隱藏，恢復後還原。

背景音樂暫停在原位置，繼續時接著播放；分頁恢復與音訊手勢不能自行解除遊戲暫停。結算仍沿用原有淡出。

## 驗證與試玩

- 測試包含長時間暫停、保留倒數餘數、動畫不跳時、舊計時回呼失效、隱藏／直向自動暫停、恢復倒數中斷、暫停退出、拖曳取消。
- 第一章兩模式三小關，驗證實際石頭等待及混合波次的待命中時間；第二章驗證實際記牌流程與限時倒數。
- 瀏覽器驗證：防禦、記憶配對及經正式入口／Skip進入的第三章均可暫停與恢復，第一章可退出至原選章頁。
- 手機實機的切換App、旋轉，以及不同瀏覽器的音樂恢復仍需使用者試玩。全部三章同一草稿分支交付，未合併主程式。
