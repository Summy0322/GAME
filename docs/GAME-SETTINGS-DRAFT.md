# 遊戲設定與章節順序草稿

- 設定分為「聲音」與「遊玩」兩個頁籤。後者提供章節順序與原有密碼跳過功能。
- 密碼開啟跳過後，阿斗仔開場介紹也會顯示 `>>`，確認「前往選章」才結束介紹；不會完成或解鎖任何章節。
- 設定、密碼及跳過確認視窗依 `game-wrapper` 實際邊界置中及等比例縮放，四邊各預留12px；視窗大小不受超寬螢幕黑邊影響。橫放、視窗縮放和螢幕鍵盤造成的舞台變化會重新計算。
- 「是否按章節順序遊玩」初始為「是」，第一章開放，第二、三章鎖定；完成前一章後解鎖下一章。
- 選「否」會開放所有尚未完成章節，既有完成紀錄不清除。重新選「是」按完成紀錄重新計算可玩章節。
- 順序偏好只有按「鎖定」才會在重新整理後保留；未鎖定一律回到「是」。鎖定後是／否暫時不能更改，再按一次可解鎖；解鎖保留當次選擇，但下次回到「是」。重設進度遵守目前偏好：順序模式只開放第一章，自由模式開放三章。
- 完成章節仍沿用目前設計，需重設進度才重新遊玩；本次未新增單章重玩功能。

## 試玩重點

1. 新進度只可選第一章，完成後第二章開放，再完成第二章後第三章開放。
2. 遊玩頁籤切換是／否，確認既有完成紀錄保留；重新整理確認偏好保存。
3. 不同寬高及安全區下，設定／密碼／確認視窗完整留在16:9舞台內，兩頁都不需捲動。
4. 原有三條音量、靜音停用與密碼跳過功能維持運作。
