# 策略配對：守夜之旅

入口：夜間目錄 → 記憶挑戰卡片右上的「策略玩法」→ 開始挑戰。

這是獨立的五場短局；原有限時、無限配對與防守保持原玩法。每次翻兩張、完成判定後才推進一步，成功或配錯都算一步。思考、記憶展示、動畫與暫停不消耗步數。每場公開當前對手生命、護甲與距離下次攻擊的步數和傷害。

卡片圖案與效果固定對應，並在牌面顯示完整效果名稱：攻擊造成基礎 2 傷害；護盾增加 2，最多 6；恢復最多 2 生命；蓄力增加 2，最多 4，下次攻擊消耗蓄力並穿透護甲。最後一擊先結算勝利，不讓已被擊倒的對手同一步反擊。護盾逐點抵銷傷害，剩餘護盾保留至本場後續攻擊。

一般版十二張牌、初始生命 12；小朋友版十張牌、初始生命 14，對手生命較少、每段攻擊多留一步且傷害降低。每次鋪新牌先展示牌面；若一盤配完仍未擊倒對手，就重新鋪牌，對手生命與攻擊倒數不中斷、不重設。

五場分別介紹普通節奏、較短倒數、大傷害、護甲與綜合首領。擊倒前四位後選一項能力：攻勢提高每組攻擊；守勢提高護盾並在擋傷時蓄力；補給提高生命上限並恢復生命。攻勢與守勢各最多升兩次。生命與能力升級保留到本局結束，護盾與蓄力於每場開始清空；選擇畫面會說明此規則。

生命歸零或擊退第五位後結算。保留 350ms 最後命中回饋後才換畫面；其間不接受翻牌，並隨遊戲時鐘暫停。離開時取消回呼，避免退出後突然跳結算。結算顯示擊退數、總步數、生命與準確率。分數為每位暗影 100 分，加上最多各 25 分的生命比例與準確率獎勵，避免無限鋪牌刷分。紀錄使用 `tactics:memory:<年齡>`，與原挑戰分開。

使用既有配對素材、音效系統與暫停／返回確認。翻牌成功後以合成音效區分攻擊、防守、支援及受傷；重複判定、場間選擇與過期回呼均有保護。新局重設生命、能力與場次。

驗證：一般版與小朋友版皆用瀏覽器實際點牌跑過五場通關、生命歸零、重開與暫停退出；檢查 568×320、844×390、1280×720 的卡片與戰況欄範圍。純邏輯測試涵蓋步數、攻防、恢復、蓄力穿甲、升級上限、換盤、最後一擊與退出後回呼失效。快取 `game-v102`。

設計參考的是簡單操作下的情境選擇，而非照搬遊戲內容：
- [Pairs & Perils 官方介紹](https://store.steampowered.com/app/3179860/Pairs__Perils/)：配對效果與公開的敵方攻擊倒數。
- [Shogun Showdown 官方介紹](https://store.steampowered.com/app/2084000/Shogun_Showdown/)：時機、組合與局內升級。

本版是可試玩的第一版。自動化與模擬能驗證規則及不同策略的結果，不能證明玩家一定覺得耐玩；下一步依實際試玩調整，見 [開發規劃](DEVELOPMENT-ROADMAP.md)。
