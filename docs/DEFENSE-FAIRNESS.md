# 防禦加速後的判定修正

## 石頭提示

無限防守的石頭等待提示移入右上角波次卡片下方，文字縮為「避開石頭」，配合霧藍進度條。等待開始時顯示、結束時收起，避免原本懸浮提示與波次卡重疊。

## 判定保護

- 挑戰模式取消固定 200ms 滑動冷卻；不同方向的獨立手勢可連續作答，重複方向由該波自身排除。已答對的一般目標不再重複發射。
- 一般、多方向及混合題仍以「有效時間內收到正確方向」為準；命中動畫與石頭等待不會被反應時限誤判為漏接。
- 手勢綁定開始時的波次與遊玩編號。跨波放手、取消手勢、多點觸控、暫停前未結束的手勢，不會套到新題或誤打石頭。
- 重擊發射時若已有方向正確且仍在 500ms 有效期內的盾牌，立即判定格擋成功；完成標記先於加分與清理，避免重複結算。提前過久、錯方向及漏接仍按原規則處理。
- 點燃、格擋、旋轉碰撞、旋轉結算及下一波延遲回呼均檢查波次與遊玩編號。舊點燃回呼只能取消自己的計時器，不能取消新波次點燃。
- 旋轉結束時依真正的計時器物件取消工作；舊傷害或已結束波次不能扣新波次的生命。同一波有多種真實失誤仍最多扣一命。

## 驗證

`node --test tests/*.test.cjs tests/regressions.cjs`：161 項通過。

包含一般版與小朋友版、四個難度階段、三種作答題型，驗證最後 1ms 作答、41ms 內連續三方向、重複方向、投射物命中、石頭等待與暫停。另驗證有效提前盾牌、跨波手勢、取消／多點觸控、舊旋轉回呼、真實漏接及誤打石頭的扣命。

Edge 實際動畫於 568×320、844×390 及兩種年齡模式，確認快速混合題維持三條命、石頭提示完整收在角標內、發射前 40ms 開盾可成功格擋，持續旋轉可撐過最短旋轉時限。實體手機手勢仍可依試玩回饋補充案例。
