# 防守音效與挑戰回饋

防守使用 Web Audio 即時合成短音效，沿用對話已啟用的音訊環境，不新增媒體檔。普通命中在投射物到達時播放，順序題在正確輸入時依步驟播放漸高音階；重擊格擋、旋轉成功與失誤各有不同聲音。順序題不再疊加普通命中音，同幀多方向命中合併；聲音數量有上限。

合成音效接上既有音效與整體音量／靜音設定，音量變更立即套用到正在播放的聲音。未啟用音訊、音訊暫停、分頁隱藏或遊戲暫停時不補播；暫停、離開與靜音停止目前聲音。音訊不可用不影響操作、分數與判定。

挑戰結算增加兩張資訊卡：防守顯示最長連續無失誤波數、最多兩種主要失誤及次數；同波只記一次失誤，失誤當下中斷連續紀錄。配對顯示正確配對數除以全部配對嘗試的準確率，以及最長連續正確配對；限時與無限皆記錄，每盤銜接保留整局統計，新局重設。零次嘗試不顯示虛構的準確率。最佳分數與對應波次／盤數仍沿用原存檔規則，這些新統計顯示於本局結算。

四種挑戰入口各顯示三個短重點，完整原說明移至「詳細規則」展開區，每次進入預設收起。配色沿用防守與配對各自的藍色主題，入口及結算可在小螢幕捲動。

正式練習入口與使用方式見下方接入說明；Console 順序練習仍保留。

驗證涵蓋音訊啟用、音階、音量、靜音、暫停／隱藏、音效上限、整局統計與入口規則。Edge 已以實際操作驗證順序聲音與失誤統計、配對準確率與連續紀錄，以及 568×320、844×390、1280×720 的入口／結算排版；原生 Web Audio 訊號與靜音清理通過。快取 `game-v97`。

正式練習入口已接入：夜間目錄使用固定標題「月下老街」，以「挑戰／練習」頁籤共用原卡片區域。練習提供重擊格擋、旋轉防守、順序滑動、記憶順序；點卡片直接載入實際防守引擎，不跳介紹視窗或開場倒數。保留正常命中／失誤及合成音效，失誤不扣生命，所有加減分均略過，不記錄最佳成績。每種練習固定題型、原始年齡模式速度，後續波次不混入其他題型或加速。右上可重開整次練習，或確認後離開回到練習頁籤；取消離開回到暫停選單。頁籤支援方向鍵、Home／End。Console 測試仍維持原先三條命及獨立測試行為。快取 `game-v99`。
