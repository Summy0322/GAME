# 第一階段改進：章節紀錄與資源載入

依照《遊戲重構與改進建議》核對目前實際使用的入口 `index.html`。
目前已經有 core / data / minigames 分工、Loading 畫面與互動遊戲，
`story.js`、`game_level1.js` 並未由入口載入，故本次不擴充舊的拼圖示範。

## 本次行為

- 已完成／鎖定的章節會沿用既有 `chapterStatus` 儲存格式，在重新整理後保留。
- 關卡選單提供「重設章節進度」，確認後三章恢復初始開放狀態。
  此按鈕僅重設章節紀錄，不刪除其他系統的收藏或設定。
- 損壞的存檔、非預期欄位、無法使用的 localStorage 不會中斷遊戲啟動。
- 章節對話與選項的背景圖加入等待預載；開場影片從實際的 source 標籤取得。
- 載入項目去重、單一資源只計算一次；15 秒未完成會繼續遊戲，避免畫面一直卡住。
  失敗或逾時的圖片仍可能暫時缺圖，並未保證資源已成功下載。
- 新載入工作會取代舊工作的完成回呼，避免延遲回應切回舊場景。
- 移除不存在的 MemoryGame.js 引用，保留實際使用的 MemoryGameV2.js。
- Service Worker 快取版本升為 game-v4。既有頁面可能需關閉所有遊戲分頁再開啟以完成更新。

## 本次範圍與後續

儲存粒度為章節完成紀錄，不是對話行數或小遊戲中途續玩；年齡模式仍於每次啟動選擇，
並沿用原本兩種模式共用的章節紀錄。沒有更動劇情、美術與各小遊戲的玩法或計時規則。

完整 ES Modules 遷移需要同步處理 HTML 行內事件、window 介面、資料檔載入順序，
以及 Service Worker 離線相依，應另開一階段逐步遷移與驗證。
GameState.js 目前未接入入口，直接改寫它不會改善實際執行中的遊戲。
中途續玩則需先設計可序列化的對話分支、收藏、副作用與小遊戲狀態，避免載入後重複發獎或錯跳劇情。

## 第三階段：退出清理與專案說明

- 新增 MinigameSession，集中管理互動與付款系統一次遊玩的全域事件、延遲工作與外掛提示。
- 每次 start 先清理上次遊玩；close 中斷 resize／拖曳監聽、取消計時、移除知識卡及完成提示，
  清空 DOM 與回呼引用。付款原本以不同匿名函式移除 resize 的問題已修正。
- 支援 pointercancel，拖曳途中退出或手勢被取消時恢復樣式，不送出錯誤操作。
- 完成回呼先保留再清理，避免取消／完成通知遺失；舊完成計時不能影響新遊玩。
- GameEngine 統一結束小遊戲並涵蓋付款；對話結束時呼叫清理。
  載入途中退出後，晚到的資源回呼不會重新開啟小遊戲。
- 快取升為 game-v7，納入新共用程式；新增 README 介紹功能、啟動、架構與限制。

19 項自動測試通過，涵蓋連續進出 20 次、拖曳途中退出、pointercancel、重複完成、
舊計時與載入回呼失效等。檢查工具的 scene=cleanup 可在實際瀏覽器重現開關與拖曳退出測試。
已在 Chromium 實際執行互動／付款各 20 次開關與拖曳途中退出，cleanupOK 為 true。
此輪並非所有子系統的完整記憶體稽核：防禦／記憶遊戲的其他延遲動畫與收藏系統仍需後續檢查。

## 第四階段：遊玩穩定性與首頁操作

本輪檢查發現並修正：

- 記憶配對的記憶階段、翻牌及效果延遲改由 MinigameSession 管理；
  停止、重新開始與結算時取消舊工作，退出時清空畫面引用，結算回呼只保留至離開結果畫面。
- 記憶遊戲原先引用不存在的 success／error／win／fail 音效，改用現有 correct／wrong。
- 打字計時可在 clear 或新對話開始時取消，舊回呼不能繼續寫入新畫面。
  函式產生的角色名稱與文字先求值再顯示。
- 小遊戲不存在時回報失敗，避免誤判通關；已退出或被取代的完成回呼不再生效，
  同一次遊玩的完成通知只觸發一次。
- 首頁圖片容器改為原生 button，保留圖片與尺寸，提供鍵盤 Tab／Enter 與焦點外框。
- 快取升為 game-v8；27 項回歸測試通過。Chrome 實測記憶遊戲連續重進 20 次，
  memoryCleanupOK=true；首頁 Tab 可移動焦點，Enter 可啟動載入流程。

後續優先順序：補齊離線相依並測試 PWA、縮減大圖與注音字型載入量、
檢查防禦／收藏的延遲效果，再逐步增加小遊戲鍵盤操作與音量／閱讀速度設定。
本輪未更動資源畫質、玩法難度及整體構圖，也未宣稱完成全遊戲無障礙驗證。

## 第五階段：第一章五項遊玩節奏調整

1. 三個防禦小關的混合回合，正確目標都在時限內滑動後，取消原本的作答逾時，
   等投射物實際命中，再保留一般版 600ms／小朋友版 800ms 的石頭避讓判定。
   這段期間滑向石頭仍扣分，也不能取得該石頭的避讓獎勵。
2. 純石頭回合改為一般版 1400ms／小朋友版 1900ms，顯示縮減進度條與避讓完成訊息。
3. 第一個肉圓小關兩種模式均為 10 波：四方向練習、一波純石頭、雙向與混合辨識、
   最後三方向綜合挑戰。第二／三小關的波次順序與重擊／旋轉規則保留。
4. 正確完成後的回合間隔為一般版 320ms／小朋友版 450ms；預備時間為 250ms／350ms。
   原有肉圓、火焰、黃豆的作答時限保留；漏接仍等完整時限並按原規則扣分。
   普通與多方向攻擊均等待命中動畫完成再切換，及時作答不因飛行時間被誤判逾時。
5. HUD 顯示「第幾／共幾波」；END 不計入波次，第一小關另顯示練習／辨識／挑戰階段。

新增每回合身分與完成保護，回合切換、退出後的舊回呼不會重複加分或跳波；
防禦遊戲重進改用遞增遊玩編號，避免同一毫秒內重啟的舊回呼被誤認為同一次遊玩。
快取升為 game-v9，納入新攻擊流程檔。
