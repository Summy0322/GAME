# 直接測試順序防守

開啟遊戲網頁，按 `F12`，切到 **Console（主控台）**。輸入下列其中一行，按 Enter：

```js
GameTest.order()                 // 編號一直保留
GameTest.order('memory')         // 先展示編號，再隱藏
GameTest.order('stone')          // 編號保留，混入石頭
GameTest.order('memory-stone')   // 編號消失，並混入石頭
```

直接從目前選擇的年齡模式開始，略過開場倒數；正常載入必要素材後連續出同一類三目標題，不用等到指定波次。測試保留三條命、正常的展示與作答時間。右上角標示「測試 · 不存紀錄」，結算不更新最佳成績，按「再玩一次」仍為同類測試。

可再次輸入另一條指令切換題型；結束測試可輸入：

```js
GameTest.stop()
```

也可使用暫停視窗正常退出。回到挑戰目錄重新開始即為正式玩法；測試設定不會存入瀏覽器。測試指令需要使用包含此功能的版本，重新整理後才能載入更新。
